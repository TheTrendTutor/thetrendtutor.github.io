Privacy Policy - TheTrendTutor Live Bot

Last updated: October 22, 2026

TheTrendTutor Live Bot ("the bot") is operated by TheTrendTutor and is used only on TheTrendTutor's own live streams on YouTube and Twitch.

What the bot does

The bot uses the YouTube Data API and the Twitch API to read public live chat messages on TheTrendTutor's own live streams, reply to chat commands (for example !price or !help), post scheduled informational messages, and count votes in an on-screen prediction game.

Information processed

  • Public chat messages and public display names of viewers who write in TheTrendTutor's live chat.
  • Public stream statistics such as concurrent viewer count.

The bot does not request or store viewers' email addresses, passwords, payment details or any private account data. The only Google account the bot connects to is TheTrendTutor's own channel account.

Use and retention

Chat messages are processed to answer commands and count votes. Display names may appear briefly on the stream, for example in a thank-you message. Technical logs are kept for up to 30 days for troubleshooting and then deleted. No data is sold, shared with third parties, or used for advertising.

Google and YouTube

The bot uses YouTube API Services. By interacting with the bot on YouTube you also agree to the YouTube Terms of Service. See also the Google Privacy Policy. Access tokens are stored only on the owner's private server and can be revoked at any time from the Google Account permissions page.
